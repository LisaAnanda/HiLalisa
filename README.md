# Lisa Afri Nanda — Personal Website

Website profil personal bernuansa aesthetic minimalis dengan aksen pastel.

## Deploy ke GitHub Pages
1. Buka repository `LisaAnanda/HiLalisa.github.io`.
2. Tambahkan atau ganti file `index.html` di root repository dengan file dari paket ini.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, pilih branch `main` (atau branch default repo) dan folder `/ (root)`, lalu **Save**.
5. Tunggu proses deploy selesai. URL publik biasanya berbentuk `https://lisaananda.github.io/HiLalisa.github.io/` untuk repo proyek; jika repo diubah menjadi repository user site bernama `LisaAnanda.github.io`, URL-nya `https://lisaananda.github.io/`.

Konten pengalaman dan pendidikan disusun berdasarkan informasi publik yang ditemukan. Silakan tinjau dan ubah bagian teknologi, uraian pekerjaan, atau detail lain agar benar-benar sesuai dengan pengalaman Anda.
